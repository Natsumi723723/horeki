# 歩歴（ほれき）— Horeki

**歩いた道が、自分の地図になる。**

GPSで街歩きを記録するPWA。歩けば歩くほど、自分だけの街歩き地図ができていく。

- 歩いた道をGPSで記録する
- 過去の記録を地図で振り返る
- 現在地まわりの史跡・寺社・文化施設を見つける
- 歩いた距離が積み上がっていく

Androidアプリではなく **Webアプリ（PWA）** として作ってある。ホーム画面に追加すると、アドレスバーのないアプリとして起動する。インストール不要、ストア審査なし、URLを送るだけで友達に渡せる。

---

## 使い方（渡された人向け）

1. Androidの **Chrome** で URL を開く
2. 位置情報を **「アプリの使用中のみ許可」** にする
3. メニュー（︙）→ **「ホーム画面に追加」**
4. ホーム画面のアイコンから起動する

画面は下のタブで4つ。

| タブ | 何をする画面か |
|---|---|
| **MAP** | 現在地と歩行記録。ここで「歩き始める」を押す |
| **記録** | 過去の街歩きを新しい順に見る |
| **まわり** | 現在地の周りの史跡・寺社・博物館・公園 |
| **MY MAP** | これまで歩いた軌跡を全部1枚の地図に重ねて見る |

### 歩くとき

「歩き始める」を押す → 歩く → 「終了」→「終了して保存」。

歩いている間は **画面をつけたままにするのが確実**（後述）。

---

## ⚠️ 正直に言っておく制約（重要）

Webアプリなので、ネイティブのAndroidアプリと違って **バックグラウンドでのGPS記録に制限がある**。

- 記録中は **Wake Lock** で画面が消えないようにしている
- それでも、**他のアプリに切り替えたり、電源ボタンで画面を消すと、ブラウザがGPSを止めることがある**
- 止まっても記録は壊れない。復帰すると続きから記録され、途切れた区間は地図上で線を結ばない
- 数秒ごとに端末内に退避しているので、ブラウザが落ちても記録は残る（次回起動時に「中断された記録があります」と出る）

**確実に取りたい日は、画面をつけたまま、アプリを前面にしておくこと。** ポケットに入れて画面オフのまま2時間歩く、という使い方は保証できない。ここだけはネイティブアプリに勝てない。

それが許容できないなら、Kotlin + Foreground Service のネイティブアプリを作り直すことになる。

## そのほかの仕様

### GPSの扱い

- **精度が50mより悪い測位は捨てる**
- **数百m突然ジャンプした点・徒歩ではありえない速度（29km/h超）の点は外れ値として捨てる**
- 精度が悪いほど「動いていない」とみなす幅を広げる（ノイズで距離が水増しされない）
- 60秒以上測位が途切れたら、その前後を線で結ばない（通った道が分からないので距離にも足さない）
- 立ち止まっていただけの時間は、途切れとして扱わない
- 測位を処理する間隔は最短3秒（バッテリー対策）
- 距離は緯度経度の差ではなく **球面上の距離（Haversine）** で計算

GPSが弱いときは「GPS信号が弱くなっています」と出るが、**記録は止まらない**。

### オフライン

- GPS取得 / 歩行記録 / 距離計算 / 過去記録の閲覧 → **オフラインで動く**
- 地図タイルは一度読んだぶんがキャッシュされるので、通った道はオフラインでも表示される
- 周辺スポット検索だけはオンライン必須

### データ

- 端末内の **IndexedDB** に保存。クラウド同期なし、アカウントなし、送信先なし
- アプリを更新してもデータは消えない
- 将来のバックアップ／同期のために `exportAll()` / `importAll()` をデータ層に用意済み（UIは未実装）

⚠️ **`src/config.js` の `DB_NAME` とストア名は絶対に変更しないこと。** 変えると既存の記録が読めなくなる。

### 地図とスポットのデータ元

- 地図タイル：**OpenStreetMap**（APIキー不要）
- スポット：**Overpass API**（OpenStreetMap のデータ。APIキー不要）
- 取れなかったときは多摩川周辺のサンプルデータにフォールバックし、画面にその旨を出す

**APIキーは1つも使っていない。** ソースにキーを埋め込む必要がない構成にしてある。

Overpass の公開サーバは無料な代わりに **不安定で、混んでいると10〜20秒かかる**。UIではローディングを出し、10秒でエンドポイントを切り替える。

## 開発

```bash
npm install
npm run dev
```

### 歩かずにGPS記録を試す

```bash
npm run dev
```

を起動して `http://localhost:5173/?mock=walk` を開くと、東京駅まわりを時速4.9kmで歩く**シミュレータ**が動く。精度の悪い測位と数百mのジャンプもわざと混ぜてあるので、外れ値除去の確認もできる。

`?mock=walk` は開発時のみ。本番ビルドではコードごと消える。

### テスト

```bash
npm test
```

距離計算・外れ値判定・セグメント分断・標高・表示フォーマットのテスト。

### アイコンの再生成

```bash
npm run icons
```

`scripts/gen-icons.mjs` が藍地に生成りの道のアイコンを生成する（依存ライブラリなし）。

### ビルド

```bash
npm run build
```

cd /Users/nachumin/horeki

## 構成

```
src/
  config.js       アプリ名とDB名。名前を変えるならここだけ
  geo.js          距離計算・GPS外れ値判定・表示フォーマット（純関数のみ）
  db.js           IndexedDB。UIから直接触らない
  useRecorder.js  GPS記録の心臓部。watchPosition / Wake Lock / 自動退避
  spots.js        Overpass API から周辺スポットを取る
  MapView.jsx     Leaflet のラッパー
  RouteThumb.jsx  一覧用のSVGルート図（タイルを読まないので軽い・オフライン可）
  App.jsx         タブと画面の切り替え
  MapScreen.jsx / RecordScreen.jsx / WalkDetail.jsx / ExploreScreen.jsx / MyMapScreen.jsx
  mockGeo.js      開発用の歩行シミュレータ（本番ビルドでは消える）
```

データ層（`db.js` / `geo.js` / `spots.js`）はUIから完全に分離してある。クラウド同期や写真の紐付けを足すときは、UIを触らずにデータ層から広げられる。

GPSの点は `{lat, lng, t, acc, alt}` の配列で持っている。写真を紐付けるなら、この点に `photoId` を足すか、`walkId` + 撮影時刻で引く形が素直。

## デザイン

和モダン。墨・藍・生成り・茶。アクセントに朱を少しだけ。

- 地図タイルにセピア寄りのフィルタをかけて、古地図・和紙の質感を出している（線の色は変えない）
- 見出しと数字は明朝体。「高級な旅行ノート」の質感はここで出る
- ダークモードは `prefers-color-scheme` で自動。地図タイルは反転フィルタに切り替わる
- 和柄・筆文字・桜のイラストのようなベタな和風要素は使っていない

色は `src/styles.css` の `:root` に集約してある。
